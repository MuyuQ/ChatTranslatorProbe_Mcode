# 聊天助手使用说明

[返回项目首页](../README.md) · [更新记录](../CHANGELOG.md)

适用于 0.17.16。设置在账号内共享，升级保留已保存的开关、颜色与术语解释。

## 开启与显示方式

首次安装需要完全退出并重新启动游戏，确认 `Interface/AddOns/ChatTranslatorProbe_Mcode/ChatTranslatorProbe_Mcode.toc` 存在且插件已启用。输入 `/chatassist` 打开设置，在“翻译设置”中开启聊天翻译。

| 模式 | 命令 | 行为 |
|---|---|---|
| 替换原文 | `/chatassist mode mixed` | 在原位置显示已知术语的中文，保留未知部分；可通过 `[原文]` 查看原句 |
| 注释保留 | `/chatassist mode annotate` | 保留原词，在识别的表达后附上中文解释 |
| 术语列表 | `/chatassist mode terms` | 保留原消息，另外列出识别出的术语与解释 |

无法确认最终聊天行的正文归属时，插件保留原行。显示方式和颜色只影响后续消息，不会重写聊天框里已有的全部内容。含义明确且完整匹配的少量短句可以给出整句译文，其他内容仍属于局部替换。

物品、成就、任务和法术链接及其显示名不参与词典扫描，原有链接和颜色保留。玩家名、数值及未识别条件保留。不能只根据缩写猜测专精、岗位或掉落限制。

## 分类颜色

在“翻译设置”中开启“按类别着色”，分别选择副本相关、职业／职责、其他文本三类颜色。颜色选择器支持预览、确定和取消；“恢复默认颜色”不清除翻译开关或自定义术语解释。

成就和物品等链接仍使用自己的颜色。关闭分类着色后，译文使用“其他文本”颜色，已有链接保留原色。

## 通用语

“屏蔽与过滤”中的“屏蔽通用语”默认开启，按游戏事件的语言字段识别 `Common`、`通用语`、`通用語`，不扫描正文是否提到这些词。它按语言标记生效，不判断正文是否可读；如果正常聊天也带有该标记，可关闭这个显示开关。

关闭只恢复显示。此类消息始终排除于本插件的样本记录和已接入的 ElvUI 新增历史；旧历史不回写。其他语言及系统消息不受这个开关影响，插件也无法恢复服务器已经变换的跨阵营原句。

## 广告、屏蔽词与白名单

公会招募屏蔽及金币、账号、代练、付费代刷四类广告屏蔽均默认关闭。开启后按选择的聊天来源生效，默认来源为公共频道和喊话。自动判断采用保守规则：普通提及金币、链接、公会或代刷服务不必然触发。

自定义屏蔽词按使用者明确填写的内容匹配。英文按完整词或短语，忽略大小写并合并连续空格；中文按连续文本。每组最多 100 条，每条最多 120 字节；不接受颜色或链接控制符，也不执行 Lua 模式。

白名单玩家按完整姓名匹配，忽略大小写；事件带服务器后缀时需要一起填写。白名单文本按词或短语匹配。白名单可放行公会招募、广告类别和屏蔽词命中的消息，不覆盖通用语屏蔽及重复去重。

## 重复消息

在“屏蔽与过滤 → 重复消息”调整独立开关、来源和统一间隔。可选 10、30、60、120、180、240、300 秒，默认 30 秒。

仅同一玩家完全相同的原文参与去重。首次实际显示开始计时，隐藏的重复消息不延长间隔；原文与译文一起隐藏。不同玩家、大小写或空格不同的原文分别显示，不模糊合并相近的招募。

开启“合并公共频道与喊话”后，同一发送者的相同原文在所选公共来源共用间隔。公共来源包括喊话、内置频道及 global/world；地方防务属于内置频道。关闭合并后，各频道分别计时。其他自建频道不参加公共合并，取消勾选的来源不去重。

历史回放不去重。缺少可靠事件标识或无法确认消息身份时保留原文，不猜测身份。多个订阅窗口共享接收事件的判断，各窗口按自己的接收规则显示。

## 本地记录与词典反馈

在“本地记录”中开启或关闭采集、查看最近 20 条漏译或屏蔽样本，或清空所选列表。漏译最多保留 1,000 条，屏蔽样本最多 100 条；重复样本累计次数并更新最近时间，超限淘汰最久未出现的样本。

采集与翻译开关独立。部分翻译和没有提示的消息都可能进入漏译记录；历史回放、通用语、未掌握的游戏语言以及含俄文字母的漏译样本跳过。异常旧记录会隔离保留；较高存档版本暂停辅助并保留原表。

正常退出或 `/reload` 后，游戏把账号共享的 `McodeChatProbeDB` 写入：

```text
WTF/Account/<账号>/SavedVariables/ChatTranslatorProbe_Mcode.lua
```

记录包含原文、发送者、频道、当时译文、原因、出现时间、次数和版本。分享前检查内容，避免公开不希望分享的私聊或身份信息。插件不联网、不自动上传，也不自动接受外部词典变更。

词典已编入 `Engine.lua`。自定义屏蔽词用于隐藏消息，不是自定义翻译词典。`/chatassist label 中文解释` 只修改戒牧概念的中文解释，对 `disc/disco/disc priest/discipline priest` 共用；`/chatassist resetlabel` 恢复该项默认解释。

需要自行补词时，按 [AI 词典更新指南](AI_DICTIONARY.md) 准备当前插件文件、筛选记录和验证样例。

## 状态与性能诊断

输入 `/chatassist status` 查看运行版本、默认聊天和 ElvUI 接入、过滤、去重及采集计数。输出按窗口调用计数，不等于服务器消息条数；“未识别显示路径”也可能包含被其他过滤器或窗口规则正常隐藏的消息，不能直接当作错误数。

性能诊断默认关闭：

```text
/chatassist perf on
/chatassist perf report
/chatassist perf off
```

`on` 开始新一轮采样并清零，`report` 查看各阶段计数、耗时与缓存，`off` 停止采样并保留报告。诊断本身有开销，短时收集后关闭；它不测 GPU 绘制，也不能直接换算为帧率。

## 常见问题

**没有翻译：** 新装翻译默认关闭；先在设置中开启，再运行 `/chatassist status` 和 `/chatassist demo`。确认插件目录名正确、TOC 没有多套一层目录，并核对聊天接入是否正常。仅含游戏链接、未掌握语言或没有已知术语的消息可能没有译文。

**仍有英文或其他语言：** 当前为有限词典和句式匹配。施法宏、任务播报和战斗统计可能缺少固定模板；其他语言没有完整覆盖。保留原句反馈，不能把局部翻译当作完整句意。

**数字旁显示问号：** 先核对原文字符。例如部分技能通报的 `초` 是韩文“秒”，字体显示可能不完整；0.17.16 尚未增加该单位转换。目标名字的问号不能仅凭截图判断原因。

**想停用全部功能：** `/chatassist off` 只关闭翻译。完全停用请在插件管理中取消“聊天助手”，或退出游戏后移走插件目录。保留账号存档可供以后恢复设置；移除插件不会修改其他汉化插件或游戏资源。
