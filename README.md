## 0.15.4 游戏内性能诊断（2026-10-05）

默认关闭。游戏内 `/reload` 后执行 `/ctprobe perf on`，在公共频道玩一两分钟，再用 `/ctprobe perf report` 查看，最后 `/ctprobe perf off` 停止。`/chatassist perf ...` 同样可用。每次 `on` 都清零重新采样；`off` 保留报告，重载或退出后清空，不写入账号存档。修改设置不重置诊断计数，比较不同设置时需分别重新采样。

报告列出过滤、分组、实际翻译、日志采集／整理、清理和公共译文查找的次数及耗时，公共译文命中率、重复隐藏比例、聊天入口平均／最高耗时及当前缓存容量。多个窗口分别计数，历史回放另列；跳过插件处理的事件不计入。入口耗时含原聊天处理和诊断开销，各阶段可嵌套，累计耗时不能相加。停止后计数冻结，缓存容量仍反映报告时的当前状态。

优先使用 `debugprofilestop()` 毫秒计时；缺失时用低精度 `GetTime()`，短调用可能为0。异常计时单独计数，不参与平均值。诊断有额外开销，关闭时恢复原处理函数，不读计时器。133组Lua 5.1检查通过，测量与含义见[游戏内性能诊断记录](../记录/聊天助手游戏内性能诊断-20261005.md)。

## 安装与命令

将整个 `ChatTranslatorProbe_Mcode` 目录复制到游戏的 `Interface/AddOns/`，完全退出并重启客户端，在插件列表中启用。新增插件仅重载界面可能不会被扫描到。

已安装旧版原型时，继续使用原目录和保存表，插件列表显示“聊天助手”。本次更新没有新增运行时Lua文件；输入 `/reload`，再用 `/chatassist status` 核对运行版本为 `0.15.0`；如果显示旧版本，完全退出并重新启动客户端。

设置入口：`ESC → 界面 → 插件 → 聊天助手`，也可输入 `/chatassist`。主页提供指引，侧栏包含“翻译设置”“屏蔽与过滤”“本地记录”三个子页。“屏蔽与过滤”顶部为总开关与屏蔽通用语，下方三个标签：屏蔽（关键字屏蔽＋屏蔽词＋频道范围）｜白名单（玩家、文本）｜重复消息。统一间隔点击切换档位；开关立即生效，账号内所有角色共用。`ESC → 插件管理`可管理插件启用状态。

游戏内输入（所有 `/ctprobe`命令也支持 `/chatassist`）：

- `/ctprobe` 或 `/ctprobe config`：打开插件设置页。
- `/ctprobe status`：查看是否开启、默认聊天和 ElvUI 的接入状态，以及窗口输出计数。
- `/ctprobe on`：开启翻译并清空临时去重状态。
- `/ctprobe off`：关闭翻译并清空临时状态。广告、通用语屏蔽、去重和采集分别设置，关闭翻译不关闭这些功能。
- `/ctprobe demo`：输出本地合成显示样例，不发送任何服务器聊天消息，不影响实时去重状态。
- `/ctprobe mode mixed`：使用原句翻译，保留句子结构，已知术语改为中文。首次升级时默认选择此模式。
- `/ctprobe mode terms`：切回原来的英文术语与中文解释列表。
- `/ctprobe label 戒牧`：修改“戒牧”这个术语的中文解释，对全部四个别名生效。
- `/ctprobe resetlabel`：恢复该术语的内置中文解释。

修改解释后运行本地样例，可以检查 `disc`、`disco`、`disc priest`、`discipline priest` 是否一致。

显示方式保存在账号共享的插件设置中。切换显示方式会清空当前临时去重状态；已在聊天窗口里的旧提示不会重写，后续消息采用新方式。完整匹配的短句仍用 `→ 译文：`，两种方式只影响不能完全翻译的消息。

## 通用语屏蔽与记录排除

按用户要求，“屏蔽通用语聊天”默认勾选。开启后，隐藏语言标记为 `通用语`、`通用語` 或 `Common` 的玩家聊天原文和提示，涵盖默认聊天、ElvUI 实时消息及历史回放。按游戏事件的语言字段识别，不扫描正文中的这几个词；其他语言、`Universal` 及系统消息不受这个开关影响。规则按语言标记生效，不另行判断正文是正常文字还是乱码。

关闭该开关只恢复显示。通用语始终排除于本插件独立记录、接入的ElvUI新增聊天历史和后续漏译分析；翻译关闭时也排除。已有ElvUI历史或之前生成的分析文件保留。

过滤 ElvUI 历史需要对应接入保持有效，`status` 会列出 `elvui-history` 的接入状态。其他插件改写该方法时，按下面的接入检查步骤重新确认。

## 广告与自定义屏蔽

“广告屏蔽”页分别勾选出售金币、出售账号、代练和付费代刷。默认全部关闭，不因升级自动隐藏这些消息。默认作用于公共频道和喊话；私聊、小队、团队、公会等可选。

同页的“屏蔽公会招募”默认关闭，勾选后只处理已选中的公共频道与喊话。仅公会标签或提及guild不足以触发；还需明确招募动作或成员需求。普通LFM组团、公会团补人、寻找公会、否定和疑问句保留。当前规则识别英文，不保证识别所有语言和写法。关闭过滤总开关也会关闭公会招募屏蔽。

按使用者要求，0.7.1采用保守规则：消息须以WTS、Selling、I am selling等明确出售表述开头，并能确定出售对象或代刷服务，才自动屏蔽。普通提及gold、carry、account、Discord、链接，或正常LFM招募不触发。买金提醒、禁止代练的说明、转述或疑问句保留；Gold Ore／Gold Bars等物品交易与金币出售区分，不把物品交易中提到的另一个账号当作卖号。

只有服务名称或价格、没有明确出售表述的消息放行，例如`ICC carry price 20k gold`。免费、否定或含义不确定的表述优先保留；`not free`和`no payment until...`分别表示收费和延后付款，结合明确出售服务时仍可拦截。规则有意少拦截，可能放过部分广告，以减少错过正常消息的机会。屏蔽记录保留命中原因，便于调整。

“自定义屏蔽规则”页每行填写一条，点击“保存规则”一起生效。英文按完整词或短语匹配，忽略大小写并合并连续空格；gold不会匹配golden。中文按连续文本匹配。每组最多100条，每条最多120字节，不接受颜色或链接控制符，不执行Lua模式。

白名单玩家按完整姓名匹配，忽略大小写；若事件带服务器后缀，需要一起填写。白名单文本沿用上述词或短语匹配。白名单先于公会招募、广告类别和屏蔽词放行，不覆盖通用语屏蔽与去重。链接内部不扫描，原文颜色控制符不影响普通正文匹配。自定义屏蔽词仍按使用者填写的规则执行，自动广告的保守判断不取消这些显式规则。

## 重复消息

“重复消息”页提供独立总开关、“合并公共频道与喊话”及聊天来源选择。去重使用10–300秒的统一间隔（默认30秒，点击切换档位），仅同一玩家完全相同原文才隐藏，首次实际显示计时，隐藏不延长间隔。合并开启时公共频道与喊话共享间隔；公共频道与喊话参加去重，其他来源关闭。已有来源选择保留，此后用户的选择不会在重载时重置。

合并开启时，同一发送者、原文完全相同的消息在所选公共来源共用间隔，原文与译文一起隐藏。公共来源包含喊话、内置频道和global/world；地方防务属于内置频道。关闭合并后，各频道分别计时；被取消的来源不去重，其他自建频道不参加公共合并。首次实际显示启动计时，隐藏不延长间隔。不同玩家、原文大小写或空格不同分别显示；多窗口共享接收事件决定，历史回放不去重。不会模糊匹配相近的组团信息，也不会将不同团长的喊话合并。

## 本地记录

“本地记录”页可关闭采集，查看最近20条漏译或屏蔽样本，或清空当前所选列表。漏译最多1000条，屏蔽最多100条；按发送者、频道和完整原文合并，累计次数，更新最近出现时间。超限淘汰最久未出现的样本。漏译包括无提示及翻译行仍有英文片段的消息；完整固定短句译文不采集，术语列表模式的非完整译文作为部分翻译采集。屏蔽消息只进入屏蔽记录。

采集与翻译开关独立，被显示去重隐藏的再次发送也可累计次数；同一事件的多窗口调用只累计一次，历史回放不采集。通用语、窗口未掌握的游戏语言与含俄文字母的漏译样本跳过；纯中文、数字和仅有链接不作为未知英文样本。缺少有效消息标识时，仅以短期同文观察合并采集，次数可能少计；显示去重仍不猜测身份，保留原文。

记录包含原文、可分析正文、发送者、频道、游戏语言、当时提示、原因、首次及最近时间、次数和版本，保存在账号共享的 `McodeChatProbeDB.records`。正常退出或 `/reload` 后由游戏写入 `WTF/Account/<账号>/SavedVariables/ChatTranslatorProbe_Mcode.lua`。向AI提供该文件前先保存；插件不联网、不自动上传，也不自动接受AI词典变更。

## 原句翻译

翻译行仅替换已识别术语，未知片段原样保留，不表示整句已完整翻译。原文仍显示，下一行用 `→ 翻译：` 标记，将已识别的词语放到原来的位置。例如：

```text
LFM #3 ToC25N - Need, 1 Tank (BDK), 3 Healer, 6 Melee, 7 Ranged - Min 5.3+ Inspect (Only B+O+P Ress) (8/25)
→ 翻译：队伍招人 #3 十字军的试炼25普通难度 - 需要, 1 坦克 (鲜血死亡骑士), 3 治疗, 6 近战输出, 7 远程输出 - 最低 5.3+ 检查装备 (仅 装绑物品、十字军宝珠和专业图纸不分) (8/25)
```

这是部分翻译，不能当作完整句意译文。`ToC25N` 按25人普通难度的十字军的试炼识别，`BDK` 译为血DK；坦克岗位由原文 `Tank` 表达，不从鲜血专精推断岗位。不从最低数值 `5.3+` 推断它必定是装备评分。未知内容的大小写、数字、否定、条件与标点保留，不改变句子顺序。已完整识别的固定组合可以作为一段替换，例如 `B+O+P Ress` 中的加号随中文列举一同表达。连接在数字后的职业简称也在原处替换，例如 `1xDisco` 显示为 `1x戒牧`。

在 ToC25 招募语境中，`B+O+P res/ress/reserved`（含 `B + O + P` 及 `B+O+P BOE Ress` 写法）整段识别为装绑物品、十字军宝珠和专业图纸预留，不参与掷骰分配。`B` 是 BoE，`O` 是 Crusader Orbs，`P` 是 Patterns；不把三个单字母分别加入通用替换表，也不把普通 `BOP` 自动解释为这个预留组合。解释依据见 [Warmane 玩家原始问答](https://forum.warmane.com/showthread.php?t=485893)。

按用户选择，聊天中将物品预留含义统一显示为“不分”：`STS ress` 显示“锐锋暮光龙鳞 不分”，ToC25 组合显示“装绑物品、十字军宝珠和专业图纸不分”。识别语境不变；“不分”说明这些物品不参加普通掷骰分配，不表示所有掉落都不分。

翻译行的基础颜色由“其他文本”设置决定，默认浅蓝色。成就或物品链接保留自身颜色；链接结束后恢复基础颜色，不继承喊话等频道颜色。链接、链接显示名、纹理及图标不翻译，在翻译行保留原控制文本。同一术语重复出现时，每个位置均替换；术语列表模式仍只列同一概念一次。

## 分类颜色（0.6.5）

## 本地样例应显示什么

`demo` 的合成时间与实际经过时间不同。输入 0、10、29、30 秒四条相同样例时，只有 0 和 30 秒的原文及中文提示显示。随后展示大小写与完整专精名称、玩家求组、未知分配条件、否定时间条件和物品链接。

`LFM disc` 是完整译文；`LFM disc, no loot` 默认显示 `→ 翻译：队伍招人 戒牧, no loot`。`don't pull yet` 是完整译文；`don't pull until xxx` 默认显示 `→ 翻译：don't 开怪 until xxx`，保留尚未解释的否定与时间结构。切到列表模式则列出确定术语。只出现在链接中的 `disc` 不触发提示。

样例末尾还有 RS、ICC 和连写招募信息，例如：

```text
LFM RS 25nm need 2Tank RDPS MDPS 5.8 (STS ress) 18/25
→ 翻译：队伍招人 红玉圣殿 25普通难度 需要 2坦克 远程输出 近战输出 5.8 (锐锋暮光龙鳞 不分) 18/25
```

样例末尾包含上面的 `ToC25N` 招募，方便直接检查显示方式，随后还有语言字段为通用语的本地屏蔽样例。勾选屏蔽时该条不显示，演示结束的通用语拦截计数为 1；取消勾选后该条显示，计数为 0。翻译行保留人数、数值与未知限制，不声称整句已翻译。

本地样例验证当前显示方法能否呈现原文与下一行中文，不能证明服务器消息事件或所有聊天插件已经兼容。

## 真实聊天检查

分别在默认聊天与 ElvUI 聊天启用的组合中检查；当前客户端安装了 ElvUI 不表示它已开启。

1. 开启原型，在两个聊天窗口中订阅同一个公共频道，观察符合原型词库的实际英文消息。两个窗口都应在各自原文后显示提示。
2. 对实际重复消息检查30秒边界，再测试调整后的间隔。默认公共频道和喊话去重；公共频道仅含内置频道及global/world，其他自建频道默认不纳入。关闭翻译后去重仍应生效。
3. 改变其中一个窗口的订阅，让另一个窗口继续显示该频道；后者的首次消息应正常显示。
4. 保留现有聊天过滤器时，检查它隐藏的消息不会消耗原型的首次显示计时。
5. ElvUI 开启时间戳和历史回放时，检查原文、提示和链接，确认历史消息不影响后来收到的实时消息。
6. 重载后用 `status` 查看接入状态；如显示“被其他插件替换”，再运行 `on` 尝试接入，并重新检查。其他聊天改造插件仍须分别验证。
7. 在设置页开关通用语屏蔽，观察带实际语言标记的实时消息与历史回放。其他语言应正常显示；正文只是提及“通用语”的消息不应被隐藏。正常退出或重载后，核对新增 ElvUI 历史没有通用语条目，旧条目不要求自动删除。

计数按窗口计算，不是服务器消息条数。第三行增加处理次数、显示但无提示，以及其中属于游戏内未掌握语言的次数。“无法关联事件”包括缺少有效消息标识或短期事件缓存达到上限；这些消息保留原文且不去重。“未识别显示路径”也可能包括被原过滤器或窗口规则正常隐藏的消息，不能单凭这个计数判断错误。

第四行显示通用语屏蔽状态及拦截次数。拦截发生在翻译、消息身份关联和临时文本缓存之前，缺少消息标识也能屏蔽；拦截次数按聊天处理窗口调用计算，不代表不同玩家消息条数。

`status` 还显示广告类别、屏蔽词条数、采集开关及两个列表的样本数量，以及公会招募开关、拦截调用次数、公共来源合并开关和已复用的分析次数。复用次数按不同接收事件累计，窗口拦截仍按处理调用累计。喊话属于YELL，公共频道与喊话可分别取消。

带游戏语言提示且语言与该窗口的默认语言不同的消息不分析正文。此规则用于避免把跨阵营等未掌握语言的变换文本误认成英文；它不是英文、俄文检测器，也无法恢复游戏已经变换的原句。

原型接入默认聊天处理函数，以及能找到的 ElvUI Chat 模块。通用语屏蔽开启时在处理入口拦截该事件；其他消息只在一次处理过程中临时接入该窗口的最终输出方法，处理结束或出错时恢复。另接入 ElvUI 的新增历史保存方法以跳过通用语，不改写其他插件源码。没有永久替换窗口输出链，不调用发送聊天、施法或移动接口。

屏蔽与去重作用于接入的显示路径，其他插件仍会收到原始聊天事件。ElvUI新增历史跳过通用语及当前公会招募／广告／屏蔽词命中的消息，去重重复消息仍可存入其历史；旧历史不改写。公会招募和广告在翻译前拦截；同文重复先复用首次分析，再由最终输出判断隐藏，保留原聊天处理器及其他显示过滤器的调用。
